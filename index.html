PROJECT / VIVA NOTE

Input: a BITS Goa start point and destination.

Processing: the application creates two campus route models, samples live weather at multiple checkpoints, considers the D-Spine when a route touches the D-side, calculates a weather-risk score, compares the routes and selects the lower-risk option as primary.

Output: primary route + backup route + live weather + route statistics + checkpoint table + downloadable CSV dataset.

Accuracy note: landmark names are based on BITS Goa's published campus information/map. The plotted walking paths and coordinates are an approximate student-project model, not an official BITS pedestrian navigation network. The D-side hostel names (DH1–DH6) and D-Spine concept are supported by BITS Goa sources, while the plotted coordinates remain approximate until verified against an official pedestrian map. Follow actual campus walkways and access rules.
